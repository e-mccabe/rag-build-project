# Metadata

Each file must have the following metadata
- **Section** the section it is related to
- **Topic** the over arching topic it covers
- **ml_task** a specific task it relates to in the machine learning eco-system (theory, pre-processing, supervised, unsupervised, training, etc)
- **related_topics** notes any other notes in the corpus that have strong links to this note
- **summary** a one sentence summary of the file
- **keywords** a comma delimited list of up to 6 keywords related to the topic
